## [crustc: Rust's Compiler Transpiled to C for Obscure Hardware](https://github.com/FractalFir/crustc) ⭐️ 8.0/10

crustc is a three-year project that has transpiled the entirety of the rustc compiler from Rust to C, enabling Rust compilation on platforms without LLVM or GCC backends. This breakthrough opens the door to using Rust on old or obscure hardware, and it facilitates secure bootstrapping of the Rust compiler from source, as well as verification techniques like diverse double-compiling. It is the 14th attempt to compile Rust to C, transpiling the compiler’s own code rather than user applications. The developer noted difficulties humorously but expects to release the code soon.

hackernews · Philpax · Jul 2, 22:57 · [Discussion](https://news.ycombinator.com/item?id=48768464)

**Background**: Rust's standard compiler, rustc, relies on LLVM to generate machine code, which is not available for all architectures. C's near-universal compiler support makes it an attractive intermediate target. Transpiling a complex compiler involves overcoming challenges with memory management, type systems, and build processes.

**Discussion**: Commenters praised the project's dedication and originality, emphasizing it is not LLM-generated. Some proposed using crustc for diverse double-compiling to detect backdoors in the official Rust compiler. Others recalled the LLVM C backend as an alternative, while a light-hearted reference to a blender accident added humor.
