## [最高法院裁定无搜查令的地理围栏搜查令违宪](https://www.theguardian.com/us-news/2026/jun/29/supreme-court-geofence-warrants-case-decision) ⭐️ 9.0/10

美国最高法院裁定，允许执法部门获取特定区域和时间内所有设备位置数据的地理围栏搜查令，若无基于合理依据的搜查令则违宪。这一里程碑式的裁决为数字位置数据确立了新的第四修正案保护。 该裁决限制了执法部门进行大规模监控的能力，保护了数字时代个人的隐私。它树立了一个先例，可能影响科技公司处理用户位置数据以及回应政府请求的方式。 在该案中，谷歌分三批提供了位置数据：首先是犯罪现场附近的匿名设备列表，然后应进一步请求提供账户标识符等。法院强调，此类搜查侵犯了合理的隐私期望，需要搜查令。

hackernews · cdrnsf · 6月29日 15:54 · [社区讨论](https://news.ycombinator.com/item?id=48720924)

**背景**: 地理围栏搜查令是一种法院命令，迫使像谷歌这样的公司在其位置数据库中搜索在指定时间窗口内出现在特定地理区域内的所有设备。执法部门在缺乏具体调查对象时，利用它来识别嫌疑人。这种做法引发了第四修正案的担忧，因为它可能揭示许多无辜者的行踪，实际上在没有具体嫌疑的情况下将他们的数字足迹变成了证据。

## [WATaBoy：将 Game Boy 指令即时编译到 WebAssembly 超越原生解释器](https://humphri.es/blog/WATaBoy/) ⭐️ 8.0/10

WATaBoy 项目展示了在浏览器中将 Game Boy CPU 指令即时编译为 WebAssembly，其性能可超越传统的原生解释器。它通过动态地将每条指令实时翻译为 WebAssembly 模块，并利用浏览器自身的 JIT 进行进一步优化。 该技术使得网页模拟器能够达到接近原生的性能，为在不使用插件的情况下直接在浏览器中运行高要求的复古游戏打开了大门。同时，它创造性地利用了浏览器对 JavaScript 和 WebAssembly 的 JIT 豁免，规避了 iOS 等平台对应用的热编译限制。 该模拟器将每条 Game Boy 指令编译为一个独立的 WebAssembly 函数，浏览器 JIT 随后将其进一步编译为机器码，从而比纯解释器更快。在 Firefox 上，性能相比 Chrome 或 Safari 慢约 25%，凸显了浏览器优化差异。

hackernews · energeticbark · 6月29日 15:02 · [社区讨论](https://news.ycombinator.com/item?id=48720190)

**背景**: WebAssembly 是一种在现代浏览器中以接近原生速度运行的低级二进制格式。传统模拟器使用解释器，由于顺序执行指令而速度较慢。即时编译（JIT）在运行时将指令翻译为机器码，从而提高性能。在 iOS 上，应用程序不能使用 JIT，但浏览器被允许对 JavaScript 和 WebAssembly 进行 JIT 编译，这提供了一个漏洞。
