## [SearXNG: The Metasearch Engine Powering Private Web Search and Local AI](https://github.com/searxng/searxng) ⭐️ 8.0/10

SearXNG is a free, open-source metasearch engine that has gained community attention for its privacy-first design and effective integration with local large language models (LLMs) for tool calling, enabling offline and self-hosted web search capabilities. It provides a viable alternative to proprietary search engines like Google, empowering users with full control over their data and search experience. Its compatibility with local AI setups allows developers to build powerful, privacy-respecting AI agents without relying on external APIs. SearXNG aggregates results from over 70 services, supports JSON output, and runs easily via Docker. However, it may be slower than commercial search engines and occasionally triggers CAPTCHA challenges from upstream providers.

hackernews · theanonymousone · Jul 3, 20:15 · [Discussion](https://news.ycombinator.com/item?id=48779454)

**Background**: A metasearch engine does not crawl the web itself but forwards queries to multiple search engines and compiles the results. SearXNG was forked from the now-discontinued searX and adds no tracking or profiling. 'Tool calling' refers to the ability of LLMs to make structured function calls to external services, enabling them to perform tasks like web searches.

## [Jamesob's Guide to Running SOTA LLMs Locally](https://github.com/jamesob/local-llm) ⭐️ 8.0/10

Jamesob shared a practical guide detailing hardware requirements and configurations for running state-of-the-art large language models (LLMs) locally, sparking extensive community discussion on costs and trade-offs. The guide highlights the prohibitive costs ($40K+) and quality compromises of local LLM hosting, informing individuals and organizations considering self-hosting versus cloud APIs, as the AI community seeks to balance control with practicality. A recommended $40K+ build includes four $12K GPUs for near-Claude Opus performance; lower-cost options like 2x RTX 3090s (48GB VRAM) can run quantized Qwen3.6-27B, while 128GB unified memory enables DeepSeek V4 flash inference.

hackernews · livestyle · Jul 3, 15:03 · [Discussion](https://news.ycombinator.com/item?id=48775921)

**Background**: State-of-the-art large language models (LLMs) like GPT-4, Claude, and GLM typically require multiple data center-grade GPUs for inference. Running them locally is challenging due to immense memory needs; quantization reduces model size by lowering numerical precision, while unified memory architectures (e.g., Apple M-series, AMD APUs) let a single system pool CPU and GPU memory to handle larger models.
