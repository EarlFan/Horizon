## [crustc：将 Rust 编译器转译为 C 以支持老旧硬件](https://github.com/FractalFir/crustc) ⭐️ 8.0/10

crustc 是一个历时三年的项目，将整个 rustc 编译器从 Rust 转译为 C，从而在没有 LLVM 或 GCC 后端的平台上也能编译 Rust 代码。 这一突破为在老旧或冷门硬件上使用 Rust 打开了大门，并有助于从源码安全引导 Rust 编译器，以及实现多样化双重编译等验证技术。 这是第 14 次将 Rust 编译为 C 的尝试，转译的是编译器本身的代码，而非用户程序。开发者幽默地提及了遇到的困难，但预计不久将发布代码。

hackernews · Philpax · 7月2日 22:57 · [社区讨论](https://news.ycombinator.com/item?id=48768464)

**背景**: Rust 标准编译器 rustc 依赖 LLVM 生成机器码，但并非所有架构都支持 LLVM。C 语言几乎无处不在的编译器支持使其成为有吸引力的中间目标。转译一个复杂编译器需要克服内存管理、类型系统和构建流程方面的挑战。

**社区讨论**: 评论者赞扬了该项目的投入和创意，强调它不是 LLM 生成的演示。有人提议用 crustc 进行多样化双重编译来检测官方 Rust 编译器的后门。还有人回忆 LLVM C 后端可作为替代方案，而对搅拌机事故的轻松提及则增添了幽默。

**标签**: `#rust`, `#transpiler`, `#c`, `#bootstrapping`, `#compiler-tools`

## [弗吉尼亚州禁止出售精度 1,750 英尺内的地理位置数据](https://www.hunton.com/privacy-and-cybersecurity-law-blog/virginia-bans-sale-of-geolocation-data) ⭐️ 7.0/10

弗吉尼亚州颁布了一项法律（自 7 月 1 日起生效），禁止出售能够在 1,750 英尺（约 533 米）精度内识别个人位置的精确地理位置数据。 该法律回应了日益增长的隐私担忧，但由于仅限制精确数据，模糊数据仍可出售，可能削弱保护消费者的初衷。 禁令针对精度优于 1,750 英尺的数据。管辖权复杂性——例如公司在其他州注册或在弗吉尼亚运营服务器（如 AWS us-east-1）——带来了执行上的模糊性。

hackernews · toomuchtodo · 7月2日 21:03 · [社区讨论](https://news.ycombinator.com/item?id=48767347)

**背景**: 地理位置数据被移动应用和服务广泛收集。精确位置数据可能泄露个人敏感信息。此前的隐私法规（如 GDPR 和 CCPA）已开始处理数据销售问题，但美国各州法律存在差异。弗吉尼亚州此举延续了州级隐私保护扩大的趋势。

**社区讨论**: 社区评论强调该法律仅禁止精确数据，模糊数据仍可出售。关于外州公司出售数据或在弗吉尼亚服务器处理数据时的执行问题也被提出。一位用户指出该法已于 7 月生效。总体而言，对其实际影响持怀疑态度。
