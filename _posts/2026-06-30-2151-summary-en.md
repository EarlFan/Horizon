## [Memory Safe Context Switching with Fil-C](https://fil-c.org/context_switches) ⭐️ 8.0/10

The article investigates memory-safety vulnerabilities in traditional context switching mechanisms like setjmp/longjmp and ucontext, and introduces Fil-C's memory-safe solution that catches errors through panics. Context switching is fundamental to systems programming for coroutines, fibers, and exception handling, and memory errors in these mechanisms can lead to severe security vulnerabilities. Fil-C's approach could let legacy C code run safely without modification, significantly reducing attack surfaces. Fil-C uses concurrent garbage collection and invisible pointer tracking to maintain memory safety, even during complex control flow. For setjmp/longjmp, it validates that longjmp is called from an ancestor stack frame, panicking otherwise. The article also examines how register allocation and stack spilling interact with non-local jumps.

hackernews · modeless · Jun 30, 00:38 · [Discussion](https://news.ycombinator.com/item?id=48727177)

**Background**: setjmp/longjmp are C standard library functions that enable non-local jumps, often used for exception handling or coroutine-like patterns. ucontext (including setcontext, getcontext, makecontext, swapcontext) extends this to multiple cooperative threads with separate stacks. Fil-C is a memory-safe dialect of C/C++ that aims for full compatibility and catches all memory errors at runtime.

## [Linux on Sega MegaDrive: Kernel Compiled Without MMU](https://github.com/LinuxMD/linuxmd) ⭐️ 6.0/10

The LinuxMD project demonstrates that Linux can run on the Sega MegaDrive by using a kernel compiled with the `‑nommu` option, which targets systems lacking a memory management unit. This hack showcases the remarkable portability of Linux and delights the retro computing community by breathing new life into a classic console, even if its practical use is limited. The system relies on an EverDrive cartridge to supply 4 MB of RAM, since the console has only 64 KB; a QEMU fork can also emulate the setup without real hardware.

hackernews · HardwareLust · Jun 29, 15:01 · [Discussion](https://news.ycombinator.com/item?id=48720186)

**Background**: The Sega MegaDrive (1988) uses a Motorola 68000 CPU without a memory management unit (MMU), hardware that normally translates virtual addresses to physical addresses. Standard Linux requires an MMU, but the Linux kernel acquired NOMMU support through the uClinux project, merged into mainline in 2007. This feature allows Linux to boot on MMU‑less devices like the MegaDrive.
