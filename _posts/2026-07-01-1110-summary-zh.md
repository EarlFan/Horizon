## [Anthropic 推出 Claude Sonnet 5：更强代理能力，更高成本效率](https://www.anthropic.com/news/claude-sonnet-5) ⭐️ 8.0/10

Anthropic 发布了 Claude Sonnet 5，这是 Sonnet 系列的新版本，旨在更具代理能力，具备更强的规划和工具使用功能，同时比之前版本更具成本效益。 此次发布将高级代理行为引入更实惠的模型，使开发者无需承担 Opus 的高昂成本即可自动化复杂任务。然而，社区分析表明，对于高要求任务，Opus 在特定推理深度级别上可能仍更具成本效益，促使用户仔细评估其用例。 据社区基准测试，Sonnet 5 性能与 GLM-5.2 相当，但成本翻倍、速度翻倍。它在常识问答（0/3）、组合工具调用（得分 45/100）和解谜方面表现不佳。值得注意的是，在 CyberGym 漏洞发现测试中，其表现不如 Sonnet 4.6 和 Opus 4.8。当推理深度超过‘中等’时，单任务成本高于 Opus，因此对于复杂任务，使用低推理深度的 Opus 更经济。

hackernews · marinesebastian · 6月30日 17:59 · [社区讨论](https://news.ycombinator.com/item?id=48736605)

**背景**: Anthropic 的 Claude 模型家族包括 Haiku（快速廉价）、Sonnet（性能与成本平衡）和 Opus（能力最强但更昂贵）。Claude Sonnet 5 是最新版本，强调代理能力——即自主规划、使用浏览器和终端等工具，并执行多步任务的能力。这一转变反映了更广泛的行业趋势，即让 AI 系统能独立行动，减少自动化流程中对人工干预的需求。

## [Claude Code 被发现嵌入隐写标记](https://thereallo.dev/blog/claude-code-prompt-steganography) ⭐️ 8.0/10

Anthropic 的 Claude Code 被发现在其 API 请求中嵌入了隐藏的隐写标识符，很可能是为了追踪竞争对手未经授权的模型蒸馏行为。 这种隐蔽标记行为引发了对透明度和用户信任的重大担忧，因为开发者不知道他们的工具正在发送隐藏标识符，这可能影响隐私和 AI 工具的伦理使用。 该隐写术的实现方式较为粗糙，容易通过逆向工程检测到。其明确意图是识别可能进行模型蒸馏的实体，尤其是中国公司的使用。

hackernews · kirushik · 6月30日 15:44 · [社区讨论](https://news.ycombinator.com/item?id=48734373)

**背景**: 隐写术是一种将信息隐藏在其他数据中的技术，例如在文本或图像中嵌入不可见的标记。模型蒸馏是一种通过训练较小模型来模仿较大模型输出的技术，从而转移知识。在 AI 行业，Anthropic 等公司担心竞争对手利用 API 输出来未经授权地蒸馏模型，因此采取了此类隐藏对策。
