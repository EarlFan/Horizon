## [AI challenges mathematicians with faster counterexamples](https://xenaproject.wordpress.com/2026/07/20/human-mathematicians-are-being-outcounterexampled/) ⭐️ 8.0/10

The article argues that AI tools are becoming increasingly effective at finding mathematical counterexamples faster than human mathematicians. It frames this as a change in how conjectures may be tested, weakened, or abandoned during research. Fast counterexample discovery can prevent researchers from spending months or years trying to prove false statements. If paired with formal verification, it could make AI-assisted mathematics more reliable by turning conjecture testing into a more systematic part of the research workflow. A related 2026 paper, “Learning to Disprove,” describes formal counterexample generation in which large language models propose counterexamples and produce Lean 4 proofs that can be automatically checked. The main caveat is that informal AI-generated counterexamples still require verification, because a convincing-looking example may be invalid without a proof or mechanical check.

hackernews · artninja1988 · Jul 20, 19:03 · [Discussion](https://news.ycombinator.com/item?id=48983382)

**Background**: A counterexample is a specific case that disproves a universal mathematical claim, such as a conjecture that says something is true for all objects of a certain kind. Counterexamples are important because they often reveal missing assumptions, force definitions to be refined, or redirect researchers toward a more accurate theorem. Formal methods use precise machine-checkable languages and tools, such as theorem provers, to verify whether mathematical statements and proofs are correct.

The economics are especially important because cheaper model-and-tool combinations may sometimes deliver competitive results, changing how developer-tool companies choose and orchestrate LLMs. Cursor says it built a new VCS because ordinary Git-based coordination was not enough for the reported commit rate, and because the VCS layer is where conflicts and coordination signals first appear. In coding, this can mean many agents generating patches, reviewing changes, running tests, or resolving conflicts in parallel. Version control systems such as Git normally track and merge code changes, but extremely high agent throughput can make conflict detection, coordination, and evaluation a central infrastructure problem.

## [Jane Street's Incremental library gets renewed attention.](https://github.com/janestreet/incremental) ⭐️ 7.0/10

Jane Street's open-source Incremental library is being discussed as a framework for building computations that update efficiently when inputs or configuration change. The project centers on maintaining computation graphs rather than recomputing everything from scratch after each change. Incremental computation is important for systems where small input changes would otherwise trigger expensive full recomputation, such as user interfaces, build systems, financial models, and dataflow-style applications. The discussion also shows how similar ideas now appear across ecosystems, from OCaml libraries to JavaScript “signals” and streaming dataflow systems. The library models dependencies between values so that only affected parts of a computation need to be re-evaluated after a change. Jane Street's description emphasizes that Incremental can handle both simple data updates and more structural configuration changes within one framework.

hackernews · handfuloflight · Jul 21, 03:50 · [Discussion](https://news.ycombinator.com/item?id=48987822)

**Background**: Incremental computation is a technique for updating the result of a computation after inputs change by reusing previous work. In a computation graph, nodes represent intermediate values or operations, and edges represent dependencies between them. Reactive programming systems use related ideas to automatically propagate changes from source values to derived values. Build systems are another familiar example: when one source file changes, a good build system rebuilds only the targets that depend on it.

## [Gaussian Splatting brings Grace Cathedral online.](https://vincentwoo.com/3d/grace_cathedral/) ⭐️ 7.0/10

A Show HN demo presents an interactive Gaussian Splatting tour of Grace Cathedral in San Francisco, letting users explore a large real-world architectural space in a browser-like 3D experience. The project showcases how current photogrammetry-based capture can produce immersive scenes while still revealing artifacts in lighting, geometry, and realism. The demo is significant because it applies Gaussian Splatting to a complex public landmark rather than a small object or controlled scene. It points toward future uses such as richer virtual tourism, next-generation Street View, cultural-preservation scans, and VR navigation through real spaces. Community comments note that incidental surroundings such as trees, nearby buildings, a basketball court, solar panels, and apartment towers were captured alongside the cathedral, which made the scene feel broader than a simple building model. Several commenters also highlighted current limitations, especially the uncanny look of Gaussian splats and lighting that can feel subtly wrong despite high detail.

hackernews · akanet · Jul 20, 20:10 · [Discussion](https://news.ycombinator.com/item?id=48984254)

**Background**: 3D Gaussian Splatting is a real-time scene representation and rendering technique that can reconstruct photorealistic 3D views from sets of 2D photos or video frames. Instead of relying on a conventional mesh alone, it represents a scene with many small Gaussian primitives that can be rasterized efficiently for novel viewpoints. The technique is often discussed alongside photogrammetry and radiance-field methods because it turns image captures of real places into navigable 3D scenes.
