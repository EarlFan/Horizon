## [Shadcn/UI 默认组件库从 Radix 换成 Base UI](https://ui.shadcn.com/docs/changelog) ⭐️ 7.0/10

## [《命令与征服：将军》借助 AI 工具 Fable 原生移植至苹果平台](https://github.com/ammaarreshi/Generals-Mac-iOS-iPad/tree/main) ⭐️ 7.0/10

一位社区开发者使用 AI 辅助工具 Fable，将经典即时战略游戏《命令与征服：将军》原生移植到了 macOS、iPhone 和 iPad 上，并在 GitHub 上发布了该移植版。 该项目展示了大型语言模型如何大幅加速游戏移植与逆向工程，使经典游戏能够在现代苹果设备上得以保存，也引发了关于 AI 在软件移植中作用的讨论。 该移植的渲染管线采用了复杂的间接链（DirectX 8 → DXVK → Vulkan → MoltenVK → Metal），而非直接的 Metal 实现；同时，部分观点认为 Fable 仅贡献了最终的 iOS/iPadOS 支持，而非整体的 macOS 移植工作。

hackernews · asronline · 7月4日 19:41 · [社区讨论](https://news.ycombinator.com/item?id=48788283)

**背景**: Fable 是一款利用大型语言模型辅助跨平台代码移植的 AI 工具。《命令与征服：将军》是 2003 年发布的经典即时战略游戏，原本基于 Windows 平台的 DirectX 8 构建。苹果平台要求使用 Metal API 才能高效渲染图形，这使得原生移植颇具挑战。该游戏通过多层 API 转换链最终实现 Metal 渲染。
