## [OpenWrt One: First-Party Open Hardware Router Officially Released](https://openwrt.org/toh/openwrt/one) ⭐️ 8.0/10

The OpenWrt project has released the OpenWrt One, its first officially endorsed open hardware router, designed to run OpenWrt natively and serve as a reference platform for developers and enthusiasts. It addresses the demand for long-term supported, open-source networking devices, giving users control over software and extending hardware lifespan beyond vendor support, while fostering open networking hardware development. Based on MediaTek Filogic 820 SoC with WiFi 6, it offers 2.5G WAN, 1G LAN, 1GB RAM, 256MB NAND, 16MB NOR recovery, M.2 SSD slot, and USB-C console. Priced at $106 with case and antennas or $84 without, a WiFi 7 successor (OpenWrt Two) is already in development.

hackernews · peter_d_sherman · Jul 6, 18:23 · [Discussion](https://news.ycombinator.com/item?id=48808482)

**Background**: OpenWrt is an open-source Linux distribution for embedded devices like routers, enabling extensive customization beyond stock firmware. Historically, it was installed on commercial routers to extend their life. Open hardware routers make design files public, allowing community auditing and modification. The OpenWrt One is the first router designed from scratch by the OpenWrt project, ensuring optimal compatibility and long-term community support.

## [A Global Workspace in Language Models](https://www.anthropic.com/research/global-workspace) ⭐️ 8.0/10

Anthropic researchers have identified a 'global workspace' mechanism in language models, formalized as the J-space, which integrates information from specialized sub-networks. When access to this shared representation was disrupted, the model lost higher-order cognitive abilities like planning and calibration while maintaining normal conversation. This discovery improves model interpretability by showing how reasoning emerges from coordinated subsystems, and it could enable more targeted control over model behavior, potentially enhancing AI safety and reliability. The J-space is defined using the Jacobian of the model's output with respect to a hidden layer's activations; representations that are causally influential and easily verbalized cluster in this subspace. Experiments showed that preventing the model from using the J-space left basic conversation intact but impaired complex reasoning tasks.

hackernews · in-silico · Jul 6, 17:44 · [Discussion](https://news.ycombinator.com/item?id=48808002)

**Background**: The global workspace theory from cognitive neuroscience posits a central processing hub where specialized brain modules share information, giving rise to conscious awareness. In machine learning, models process information through many layers, but it's often unclear how these components coordinate to produce coherent outputs. Anthropic's research draws an analogy between this biological model and transformers, using the J-space to identify a similar integrative mechanism that underlies higher-order reasoning.

## [Linux Successfully Ported to Atari Jaguar Within 2MB RAM](https://cakehonolulu.github.io/linux-for-jaguar/) ⭐️ 7.0/10

A developer has ported the Linux kernel to the 68000-based Atari Jaguar console, booting to a Busybox shell using only the original 2MB of RAM and without requiring specialized flash cartridges. This feat showcases extreme low-level engineering and the flexibility of the Linux kernel, breathing new life into retro hardware and demonstrating that even severely constrained systems can run modern software. The port runs on the Jaguar's Motorola 68000 CPU, fits entirely within the console's 2MB RAM, and stops at a functional Busybox shell. The kernel modifications are open-sourced on GitHub.

hackernews · cakehonolulu · Jul 6, 18:35 · [Discussion](https://news.ycombinator.com/item?id=48808663)

**Background**: The Atari Jaguar, released in 1993, was marketed as a 64-bit console but used a complex multi-chip architecture with a 68000 CPU, making development difficult. With only 2MB of RAM and no typical MMU, running a modern OS like Linux is an extraordinary challenge. BusyBox is a collection of minimal Unix utilities designed for embedded systems with very limited resources.
